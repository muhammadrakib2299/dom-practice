# DOM Practice

ES6 and DOM-manipulation practice tasks in vanilla JavaScript, collected on one page.

## Sections / Features

- DOM selection exercises with `getElementsByTagName`, `getElementById`, `getElementsByClassName`, `querySelector` and `querySelectorAll` (results logged to the console), plus `appendChild` adding an item to a list
- Four buttons that change the page background, each wired a different way: the `onclick` property, a named handler and anonymous `addEventListener` callbacks
- An inline `onclick` button that rewrites a line of text, and an input that replaces a paragraph with whatever you type
- A comment box that posts the textarea's text as a new comment
- A GitHub-style delete confirmation: the **Delete** button only enables once you type `delete`
- A daily task list: add tasks, click a task to remove it

## Built with

HTML5 · CSS3 · vanilla JavaScript (ES6)

## What I practised

- The different DOM selection methods, and HTMLCollection vs NodeList
- Click and `keyup` events, and toggling the `disabled` attribute
- Creating, appending and removing elements, including event delegation

## Run locally

Open `index.html` in a browser. Open the developer console to see the selection exercises' output.
